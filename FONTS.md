# Шрифты

Шрифты теперь встроены непосредственно в проект и подключены через @font-face:
- Montserrat Bold — «Что интересует?»
- Polonium Regular/Bold — большие слова «ЗАЗЕРКАЛЬЕ» и «КИНОТЕАТР»
- Simphonia Deco — «HORROR КВЕСТ» и «HORROR КИНОТЕАТР»
- Retrogression — рукописная подсказка
- Inter ExtraLight — основной информационный текст

Это означает, что GitHub Pages будет использовать те же файлы шрифтов, а не шрифты,
установленные на компьютере посетителя.
